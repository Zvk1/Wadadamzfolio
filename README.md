# Cybersecurity portfolio template

Open `dist/content.js` to edit your name, opportunity status, links, projects, CTF entries, and certifications. Use empty URLs until your real links are ready. Set `resume` to a PDF URL or `resume.pdf` and put the file in `dist/`.

Edit `dist/index.html` for your introduction, education, location, contact invitation, and skills. Replace the example projects and tools with your own work. No achievements or credentials in this template are claims about you.

The theme selector offers Auto (follows your device), Light, and Dark. Preferences are stored locally in the visitor's browser. Project and CTF entries open detail dialogs. Contact and verification placeholders show a message until configured.

No build step is needed. Serve `dist/` with a static HTTP server. Styling lives in `dist/style.css`; interactions live in `dist/app.js`. Fonts load from Google Fonts with local fallbacks.
